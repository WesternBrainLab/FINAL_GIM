============================================================================================================================================
 FINAL_GIM (Generalized Ising Model)
============================================================================================================================================
 
 * This folder contains an implementation of the Generalized Ising Model (GIM) 
 * separated into the following components:
 * 
 * - **CONFIG.py**: Configuration module where users can adjust parameters and customize test scenarios (Set as True or False)

 * - **UTILS.py**: Utility module containing helper functions and data persistence/saving functionality. When running utils, thresholded jij is saved to data.

 * - **TEMP_SWEEP.py **: GIM simulation module that executes the model through a temperature sweep

 * - **OPTIMIZE.py**: Parameter optimization module for tuning and improving simulated model performance

 * - **GIM.py**: Core model implementation containing the primary GIM algorithm and logic

 * - **GET_RESULTS.py**: Results analysis module for extracting and generating general output from the model
